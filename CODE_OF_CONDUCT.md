# Code of Conduct

## Our commitment

We want AmbiOS AI to be a welcoming, respectful, and constructive project for everyone.

## Expected behavior

- Be respectful and assume good intent.
- Give actionable feedback focused on the work.
- Welcome different perspectives and experiences.
- Protect private information and report security issues privately.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, sexualized conduct, and deliberate disruption are not acceptable.

## Enforcement

Report concerns to the maintainers through the security contact configured for the project. Reports will be reviewed fairly and kept as confidential as practical.
