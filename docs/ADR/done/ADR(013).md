# ADR 013: ambios.* Namespace for All WebMCP Tools

## Status

Accepted

## Context

WebMCP tools need a consistent, unique namespace to avoid conflicts with other WebMCP applications and to clearly identify AmbiOS capabilities.

## Decision

Use `ambios.*` namespace for all WebMCP tools. Examples: `ambios.identity.get_current_user`, `ambios.incident.suggest_hotfixes`, `ambios.guardrails.evaluate_guardrails`.

## Consequences

**Positive:**
- Clear branding and identification of AmbiOS tools
- Avoids conflicts with other WebMCP applications
- Consistent naming pattern for developers and agents
- Easy to document and discover capabilities

**Negative:**
- Requires discipline to maintain naming consistency
- May need to refactor if namespace conflicts arise

**Neutral:**
- Need to document all tools in the namespace
- Must update tool registry and documentation
