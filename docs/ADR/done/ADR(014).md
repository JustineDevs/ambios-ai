# ADR 014: Phased Rollout from MVP to Mature Platform

## Status

Accepted

## Context

AmbiOS AI has a long-term vision spanning multiple workspace types, integrations, and governance features. Attempting to build everything at once risks missing the hackathon deadline and diluting focus.

## Decision

Implement in phases:
- **Phase 0 (MVP):** Context-Aware Hot-Fix, guardrails, approvals, audit log, one integration
- **Phase 1 (1-3 months):** Hardening, more connectors, permission simulator, workflow debugger
- **Phase 2 (3-9 months):** Platform expansion, data rights, evidence workspace, accessibility
- **Phase 3+ (9+ months):** Open web platform, marketplace, enterprise governance

## Consequences

**Positive:**
- Clear focus for hackathon MVP
- Manageable scope for each phase
- Early user feedback informs later phases
- Reduces risk of over-engineering

**Negative:**
- Some features deferred to later phases
- Need to communicate roadmap clearly
- Risk of scope creep if not disciplined

**Neutral:**
- Requires roadmap documentation and updates
- Must balance MVP quality with future extensibility
