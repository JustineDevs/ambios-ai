# ADR 007: Declarative Guardrails for Safe Agent Execution

## Status

Accepted

## Context

AI agents acting on real systems need clear boundaries and approval paths. Ad-hoc permission checks scattered across code are error-prone and hard to audit.

## Decision

Implement a declarative guardrail system that evaluates planned actions before execution. Guardrails define allowed tools, environments, budgets, approval requirements, and rollback rules.

## Consequences

**Positive:**
- Centralized policy evaluation for all sensitive actions
- Clear audit trail of guardrail decisions
- Humans retain control over high-impact actions
- Agents operate within explicit boundaries

**Negative:**
- Adds complexity to action execution flow
- Requires guardrail configuration per org or agent
- Risk of overly restrictive policies blocking legitimate actions

**Neutral:**
- Need to document guardrail schema and evaluation logic
- Must balance security with usability
