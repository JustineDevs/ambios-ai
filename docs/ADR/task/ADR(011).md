# ADR 011: Secure HTTPS-Only Transport with Infrastructure as Code

## Status

Accepted

## Context

AmbiOS AI handles sensitive operations: agent actions, approvals, budgets, and integrations. All communication must be encrypted in transit. Manual infrastructure configuration is error-prone and hard to audit.

## Decision

Enforce HTTPS-only transport for all AmbiOS AI communication. Define infrastructure as code (IaC) using Terraform, Pulumi, or Cloudflare-native configuration to manage TLS, redirects, and security policies.

## Consequences

**Positive:**
- All data encrypted in transit by default
- IaC enables reproducible, auditable infrastructure
- Reduces risk of misconfiguration
- Supports compliance requirements

**Negative:**
- Adds complexity to infrastructure setup
- Requires IaC tooling knowledge and maintenance
- Initial setup time for IaC configuration

**Neutral:**
- Need to document IaC configuration
- Must manage IaC state and versioning
