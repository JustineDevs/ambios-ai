# ADR 005: Nango for Unified SaaS Integration Layer

## Status

Accepted

## Context

AmbiOS AI must integrate with multiple external platforms (Cloudflare, Vercel, Shopify, GitHub, Notion, Jira, Google services). Building and maintaining individual OAuth flows and API clients for each provider is complex and error-prone.

## Decision

Use Nango.dev as the unified integration layer for all external SaaS connectors. Call Nango's REST API from Workers to manage OAuth, credentials, and sync workflows.

## Consequences

**Positive:**
- Single integration point for multiple SaaS providers
- Nango handles OAuth complexity and token refresh
- Reduces security risk of managing provider credentials
- Faster time-to-market for new connectors

**Negative:**
- Dependency on Nango availability and pricing
- Nango Node SDK not compatible with Cloudflare Workers (must use REST API)
- Additional service to manage and monitor

**Neutral:**
- Requires Nango project configuration and environment variables
- Need to store only connection metadata, not credentials
