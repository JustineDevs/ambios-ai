# ADR 012: WebMCP Verification Loop with Automated Testing

## Status

Accepted

## Context

WebMCP tools must work reliably in ChatGPT's in-app browser and Google Chrome with WebMCP enabled. Manual testing is insufficient for production readiness.

## Decision

Implement a verification loop that tests each WebMCP tool end-to-end after implementation. Automate testing where possible. Log verification results. Do not mark tools as complete until verified.

## Consequences

**Positive:**
- Ensures all tools work in real WebMCP environments
- Catches registration and handler errors early
- Provides confidence for production deployment
- Documents expected tool behavior

**Negative:**
- Adds time to implementation
- Requires WebMCP testing infrastructure
- May reveal browser-specific issues

**Neutral:**
- Need to define verification criteria per tool
- Must maintain test scripts as tools evolve
