# ADR 008: Immutable Action Audit Log for All Agent and Human Actions

## Status

Accepted

## Context

Teams need to know what agents and humans did, when, why, and with what result. Ad-hoc logging without structure makes auditing and debugging difficult.

## Decision

Record every agent and human action in an immutable `actions` table in D1. Store actor type, actor ID, tool ID, inputs, outputs, status, guardrail decisions, approval state, timestamps, and related resources.

## Consequences

**Positive:**
- Complete audit trail for compliance and debugging
- Agent Activity Console provides shared visibility
- Enables post-incident analysis and learning
- Supports exportable audit reports for enterprises

**Negative:**
- Increases storage requirements over time
- Need to manage data retention policies
- Slight performance overhead for write operations

**Neutral:**
- Requires clear schema for action records
- Need to index for efficient querying
