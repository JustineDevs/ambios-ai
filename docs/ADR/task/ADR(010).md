# ADR 010: Reference-Based Implementation for AmbiOS AI

## Status

Accepted

## Context

AmbiOS AI is not starting from scratch. Existing reference implementations provide proven patterns for app structure, WebMCP integration, and prompt engineering.

## Decision

Preserve the existing application routes and components while applying AmbiOS branding and behavior. Use the active `webmcp/` module for browser tool registration and verification.

## Consequences

**Positive:**
- Accelerates implementation with proven patterns
- Reduces risk of architectural mistakes
- Ensures consistency with internal standards
- Provides clear reference for future developers

**Negative:**
- May carry over unnecessary complexity from reference
- Requires careful adaptation to AmbiOS branding
- Risk of tight coupling to reference patterns

**Neutral:**
- Need to update branding and naming after copying
- Must verify all imports and paths resolve correctly
