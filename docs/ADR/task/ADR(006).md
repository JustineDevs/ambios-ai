# ADR 006: Context-Aware Hot-Fix as MVP Hero Workflow

## Status

Accepted

## Context

AmbiOS AI has many potential use cases. For the hackathon MVP, we need a single, high-impact workflow that demonstrates human-and-agent collaboration, guardrails, approvals, and auditability.

## Decision

Focus the MVP on the Context-Aware Hot-Fix workflow: incident detection, agent investigation, hot-fix proposal, guardrail evaluation, human approval, execution, and documentation update.

## Consequences

**Positive:**
- Clear, demonstrable value in a high-stakes scenario
- Showcases all core AmbiOS capabilities in one flow
- Easy for judges and users to understand
- Provides a template for future workflows

**Negative:**
- Requires incident and service data seeding for demos
- May not represent all future use cases
- Risk of over-focusing on one workflow at expense of others

**Neutral:**
- Need to create mock incident and service data
- Documentation must explain the workflow clearly
