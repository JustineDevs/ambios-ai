# ADR 009: Cloudflare Queues for Asynchronous Job Processing

## Status

Accepted

## Context

AmbiOS AI has async workloads: Nango sync processing, incident fan-out, doc proposal generation, budget aggregation, and audit log exports. Synchronous request-response patterns are not suitable for these tasks.

## Decision

Use Cloudflare Queues for all asynchronous job processing. Workers enqueue jobs; queue consumers process them with retry logic and failure visibility.

## Consequences

**Positive:**
- Decouples async work from user-facing requests
- Built-in retry and failure handling
- Scales with queue depth automatically
- Integrated with Workers runtime

**Negative:**
- Additional Cloudflare resource to manage
- Need to monitor queue health and backlog
- Jobs may fail or timeout, requiring retry strategies

**Neutral:**
- Requires queue configuration in `wrangler.toml`
- Need to define job schemas and handlers
