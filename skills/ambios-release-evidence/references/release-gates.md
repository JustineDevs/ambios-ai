# Release gate checklist

| Gate | Required proof | Result | Limitation |
| --- | --- | --- | --- |
| Source/runtime boundaries | Import/build inspection and artifact evidence |  |  |
| Type/lint/tests | Fresh command output |  |  |
| API contract | Operation matrix and live probes |  |  |
| Auth/scope | Unauthorized and authenticated checks |  |  |
| UI routes | Browser direct/refresh/state checks |  |  |
| Action governance | Approval, denial, execution, verification, audit proof |  |  |
| Deployment | Ready deployment ID, URLs, health and rewrite checks |  |  |
| Artifact size | Compressed per-runtime report |  |  |
| Public claims | Claim-to-evidence mapping |  |  |
